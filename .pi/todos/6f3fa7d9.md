M8 Artifact Store completato.

Implementazione:
- content-addressed store privato `ds4-context/artifacts/<prefix>/<sha256>` con SHA-256 verificato, `0700` directory, `0600` file, temp `wx`, fsync, rename atomico, dedup, quarantena/riparazione corruzione e path non controllabile dall'utente;
- SQLite schema v8: `artifact_objects` deduplicati + riferimenti `artifacts` source-specific con FK session/entry, provenance tool, token before/after, status available/missing/corrupt; migrazione legacy preserva object/source metadata;
- ArtifactManager rileva grandi `ToolResultMessage`, richiede mapping fingerprint esatto alla entry Pi, conserva ruolo/toolCallId/toolName/isError/details/timestamp/immagini e ordine dei blocchi non-text, sostituisce solo il testo provider-facing;
- output completo resta nel Pi JSONL canonico e nell'object cache rebuildable; observer/ephemeral disabilitati; errori size/storage/provenance fanno fail-open al messaggio Pi originale;
- reference bounded con error/head/tail/path, JSON quoting anti prompt-injection, redazione credenziali/token/private key, trattamento binary metadata-only e limite hard sui caratteri inline;
- `context_artifact_search`: Artifact ID esplicito, sessione + branch attivo obbligatori, hash ricalcolato, ricerca literal case-insensitive bounded, redacted/JSON-quoted, rifiuto binary/over-limit/missing/corrupt; risultato sotto inline threshold;
- planner riceve risultati condensati prima degli atomic groups; multi-tool call/result rimane atomico; fallback planner conserva le reference già sicure senza synthetic retrieval leakage;
- Context Manifest artifact metadata-only con canonical source/tool provenance; plannerVersion `managed-artifacts-v1`, policyVersion 4;
- `/context artifacts`, status/tokens/manifest/health/rebuild-index estesi; health verifica fisicamente hash/status; rebuild rigenera oggetti da JSONL, riconcilia riferimenti e garbage-collect;
- privacy hardening condiviso per token `ghp_` nel project index;
- docs ARTIFACTS, architecture, planner, manifest, storage, README e ADR aggiornati.

M12 Optional Native Continuation completato.

Implementazione:
- valutati `before_provider_request`, custom provider Pi `streamSimple`, OpenAI `previous_response_id`, conversation IDs e continuation già nativa di `openai-codex-responses`;
- scelto wrapper provider ristretto che delega serializzazione, auth, HTTP/SSE, tool e usage a Pi `openai-responses`;
- feature disabilitata per default; richiede `enabled=true`, consenso esplicito `allowProviderStorage=true` e profili exact `provider/model` o `provider/*` senza wildcard globale;
- le richieste eleggibili impostano `store:true`; nested summary call, observer, API non Responses, profili non registrati e payload non validi restano invariati;
- state machine volatile isolata per session/provider/model con solo SHA-256 degli item/options, response handle minimo e timestamp; nessun prompt/tool/output text conservato;
- delta inviato solo se full request options e prefisso `previous request input + previous response items` corrispondono esattamente;
- invalidazione conservativa su model/provider switch, branch/tree, compaction, shutdown/reload/degraded, expiry, option/tool/system/context-prefix change, empty delta, missing response ID/item e failure;
- errore stale/invalid `previous_response_id` prima dello streaming: soppressione dell'errore non esposto e singolo retry con full managed replay; nessun retry per auth/rate limit o failure dopo stream start;
- trasformazione continuation eseguita dopo la callback payload completa e la privacy finale; non reintroduce contenuto escluso; payload `{}` fail-closed resta ineleggibile;
- Context Manifest e diagnostica metadata-only: eligibility/consent/mode, full/sent/omitted counts, age, retry/fallback/invalidation; nessun response/conversation ID;
- `/context continuation`, status/manifest/health estesi;
- plannerVersion `managed-native-continuation-v1`, policyVersion 8;
- nessuna migration: schema SQLite resta v10, nessuna tabella/entry custom continuation;
- documentazione README, NATIVE_CONTINUATION, architecture, manifest, planner, model awareness, privacy, storage e ADR aggiornata.
